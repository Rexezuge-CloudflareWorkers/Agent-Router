# Agent-Router — Backend Data (D1/DAO Layer)

Scope: `packages/backend-data/**`. Parent index: `../../AGENTS.md`.

- All D1 access via DAOs over `D1Queryable`: `BaseDAO` (`run` + static `findById`/`deleteOlderThan` + instance `findRowById`/`deleteRowsOlderThan`/`encodeCursor`/`decodeCursor`), `UserDAO` (`upsertUser`/`getByEmail`/`getByUsernameCi`/`ensureUsername`/`setUsername`), `ProviderDAO` (per-user CRUD, unique `(user_email, name)`), `ProviderKeyDAO` (priority-ordered selectable list with active-before-degraded fallback, `recordSuccess/recordFailure/markDegraded`, `markExhausted/clearCooldown`, `resetUsage/resetDueKeys`, `disableFailing`, cascade delete by provider, Codex OAuth `createOAuthKey/updateOAuthConnected/updateOAuthRefreshed(+Conditional)/setOAuthStatus/clearOAuth/listOAuthRefreshCandidates`), `CodexDeviceSessionDAO` (device-code session create/`getActiveByKey`/`consume`/`deleteByKey`/`deleteExpiredOrConsumed`), `GatewayKeyDAO` (hash lookup with expiry, per-user list, touch, revoke, prune), `UsageLedgerDAO` (insert, cursor-paginated `listByUser`, `summarizeByUser/summarizeByProvider`, prune).
- Kit boundary: `D1Queryable`/`D1Result` and `executeWithRetry` come from `@rexezuge/d1`; `BaseDAO` keeps the closure-first `run(operation, context)` helper the DAOs were written against. `CursorUtil` (opaque pagination cursors) stays local. Hashing lives in `@rexezuge/shared` (`CryptoUtil.sha256Hex`); symmetric encryption lives in services (`KeyCrypto`), not DAOs.
- Migrations: `migrations/0001_agent_router.sql` (`users`, `gateway_keys`, `providers`, `provider_keys`, `usage_ledger`); `migrations/0002_codex_oauth.sql` (OAuth columns on `provider_keys`); `migrations/0003_codex_device.sql` (`codex_device_sessions` via `CodexDeviceSessionDAO`).
- Layer 2 (L0-only): import only `@agent-router/shared`, `@rexezuge/errors` and `@rexezuge/d1`; never `backend-runtime`, `backend-services`, or `apps/*` (enforced by `no-restricted-imports`).
