# Agent-Router — Web SPA

Scope: `apps/web/**`. Parent index: `../../AGENTS.md`.

- Vite + React 19 SPA (`src/main.tsx`: `BrowserRouter` → `SpaApp`). Build embeds `dist/index.html` into `apps/api/src/generated/spa-shell.ts` (never edit generated file). Fonts are self-hosted (`@fontsource-variable/inter`, `@fontsource/jetbrains-mono`) because the SPA CSP is `default-src 'self'`.
- `SpaApp.tsx` — thin composition root: `useCurrentUser` + `useSpaLanguage` + `useNotice` hook slices, then `AppShell` (authenticated) or `AuthShell` (landing/unauthorized) around `SpaViewRouter`. No data fetching there.
- `components/layout/AppShell.tsx` — persistent 240px sidebar (72px-less mobile: sticky top bar + slide-over drawer) with `NavLink`s for `/`, `/providers`, `/keys`, `/usage`, `/settings`, user block, active-route highlighting. `AuthShell` is the brand header/footer for anonymous routes.
- `components/layout/SpaViewRouter.tsx` — routes: `/` (Dashboard or Landing), `/providers`, `/keys`, `/usage`, `/settings` (all gated by `Unauthorized`), `*` (localized 404 `EmptyState`). Views in `src/views/`; shared `ui/` primitives in `src/components/`.
- Views: `DashboardView` (KPIs, endpoint tabs + curl, provider health, recent activity, quick-action cards), `ProvidersView` (decomposed into `views/providers/`: provider CRUD + per-provider key pools, status badges, usage/cap progress, rotate/reset/enable/delete and Codex device/import flows via dialogs rather than `prompt()`), `SearchProvidersView` (`views/searchProviders/`: same CRUD/key-pool shape for Brave/Tavily, request caps only), `GatewayKeysView` (mint dialog, copy-once banner + copy button, expiry/last-used table, revoke confirm), `UsageView` (KPI tiles, Recharts daily-token area chart, per-provider bars, filterable ledger + Load More), `LandingView` (hero, quickstart snippet, feature grid), `SettingsView` (profile + language).
- API access: `src/lib/api.ts` (`apiGet/apiPost/apiPatch/apiDelete`) + `src/services/*` (`providerService`, `gatewayKeyService`, `usageService`, `userService`); `src/types.ts` (router domain types only, including `UsageSummary.daily`/`failedRequests`/`avgLatencyMs`).
- i18n: `src/i18n.ts` (i18next + `react-i18next`) — single `canonicalizeLanguageTag`; bundles `src/locales/en|zh-CN/translation.json` (fully mirrored, zh-CN translated). Validate with `pnpm run validate:locales`.
- **Title Case applies to headings, labels, buttons and nav items only.** Descriptions, hints and empty-state copy use sentence case. Keep `{{placeholder}}` parity across locales.

- Primitives from `@rexezuge/web`: `AppPage` (wrapped by the local `layout/AppPage` for a shared `max-w-7xl`), `ReadOnlyField`, `ModalShell`, `PageState`, `RefreshButton`. Local `ui/` primitives: `Button` (variants incl. `outline`, `danger`, sizes `xs…lg`/`icon`), `Card` (`default|subtle|interactive|metric`), `Badge`/`StatusBadge`, `Input`/`Select`/`Textarea`/`Field`, `Progress`, `Skeleton`/`SkeletonRows`, `StatTile`, `Table`, plus shared `CopyButton`, `ConfirmDialog`, `EmptyState`, `SegmentedTabs`.
- Tokens live in `globals.css` (`@theme`): neutral zinc surfaces + indigo accent. Keep the `--color-surface-* | --color-border* | --color-text-* | --color-accent*` names — the kit primitives read them.
- Local hooks `useNotice`/`useSpaLanguage`/`useCurrentUser` keep their `{ type, text }` notice shape; the kit hooks use `{ kind, message }`, so they are not interchangeable without a call-site rewrite.
