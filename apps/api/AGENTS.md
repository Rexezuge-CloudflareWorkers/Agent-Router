# Agent-Router — API Worker

Scope: `apps/api/**`. Parent index: `../../AGENTS.md`.

- `src/index.ts` — `fetch`/`scheduled` via `AgentRouterWorker`; re-exports `CronTasksWorker` from `@agent-router/background` for the DO binding.
- `src/workers/AgentRouterWorker.ts` — Hono composition root. Public: `/`, `/health`, `/docs`, proxy routes. Protected `/user/*` behind `userAuthentication()`. SPA catch-all serves `SPA_HTML` for `/`, `/settings`, `/providers`, `/keys`, `/usage`, `/user/*`; else `404`.
- `src/workers/ProxyGateway.ts` — `ProxyGateway` Durable Object (`PROXY_GATEWAY`), exported from `src/index.ts` for the binding. Sharded `idFromName('key:'+gatewayKeyId)`; dispatching on the forwarded pathname; owns body parsing, provider resolution and the upstream call. Reads identity from `x-agent-router-user-email` / `x-agent-router-gateway-key`, which the worker always overwrites (never trusts a client value). Stateless — no storage, alarms or `blockConcurrencyWhile`.
- `src/workers/routes/` — `ProxyRoutes` (gateway authentication + forwarding only: `/v1/chat/completions|embeddings|responses`, `/anthropic/v1/messages`, `/gemini/v1beta/models/:action` go to `PROXY_GATEWAY`; `/v1/models` and `/commandcode/v1/models` stay local. Never read the proxy body here), `ProviderRoutes` (provider + nested key CRUD/rotate/reset + Codex key create/device-start/device-status/token-import/disconnect; device flow needs no redirect URI), `GatewayKeyRoutes` (mint/list/revoke), `UsageRoutes` (summary incl. zero-filled `daily` buckets / ledger), `UserRoutes` (`/user/me`, rename).
- `src/middleware/` — `MiddlewareHandlers.userAuthentication()` (`/user/*`, Access + `upsertUser`) + `gatewayAuthentication()`/`requireGateway()` (Bearer `ar_…` → `{userEmail, keyId}`) + `scopeMiddleware` (one `Container`+`ServiceContext` per request) + `rateLimit` (per-isolate buckets, fail-open) + `securityHeaders` (incl. `no-store` on provider/key JSON).
- `src/generated/spa-shell.ts` — generated by web build; do not edit.

## Auth

- `/user/*` — Cloudflare Access via `AccessAuthService`: `DEMO_MODE` → `DEV_AUTH_EMAIL` → JWT (`cf-access-jwt-assertion` vs `TEAM_DOMAIN`/`POLICY_AUD`) → `ctx.access` fallback; upserts user on success. Never trust `Cf-Access-Authenticated-User-Email`.
- Proxy — gateway keys via `GatewayKeyService.authenticate` (active + unexpired, `last_used` touch best-effort); accepts `Authorization: Bearer ar_…` or Anthropic-style `x-api-key`; `401` on missing/invalid.

## Composition

- Handlers resolve via `createRequestScope(c.env).get(Tokens.X)` (or `getScope(c)` from `scopeMiddleware`).
- Never import `@agent-router/backend-data/dao` values in routes (type-only allowed, enforced).
